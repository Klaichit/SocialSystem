# SocialSystem

ระบบทำคอนเทนต์ carousel สำหรับ **24sEnergy** (BESS · Solar PV · EV Charging)
แบ่งเป็นสองส่วน: ตัวสร้างภาพ กับ vault สำหรับคิดและร่างเนื้อหา

## โครงสร้าง

```
builder/
  index.html        เครื่องมือสร้าง carousel (เปิดในเบราว์เซอร์ได้เลย ไม่ต้องติดตั้ง)
  templates.json    ชุดเทมเพลตทั้งหมด — เพิ่ม/แก้ layout ที่ไฟล์นี้
vault/
  Obsidian vault สำหรับคิดหัวข้อ ร่างข้อความ และติดตามสถานะโพสต์
```

## builder

เปิด `builder/index.html` ด้วยเบราว์เซอร์ (ต้องต่อเน็ตเพื่อโหลดฟอนต์กับ html2canvas)

ทำอะไรได้:
- เทมเพลต 26 แบบ แบ่งเป็น เน้นหัวข้อ / โชว์สินค้า / อื่น ๆ ดูรวมได้ในหน้าแคตตาล็อก
- สัดส่วน 4:5, 1:1, 9:16, 3:4 สลับได้ทุกเมื่อ
- ฟอนต์ไทย 24 ตัว แยกฟอนต์หัวข้อ/เนื้อความ/ตัวเลข พร้อมสไลเดอร์ขนาดรวม
- ชุดสัญลักษณ์ 6 แบบ (✓✕ · ⊕⊖ · ◆◇ · ■□ · +− · ตัวเลข)
- แถบปรับสไตล์รายข้อความ: ขนาด น้ำหนัก การจัดวาง สี
- ตัวเช็คข้อความล้น/ทับกัน แสดงผลสดขณะพิมพ์
- Export PNG ตามสัดส่วนที่เลือก ทีละใบหรือทั้งชุด
- วิเคราะห์ภาพสไลด์อ้างอิงแล้วแปลงเป็นเทมเพลตใหม่ (ดูหัวข้อถัดไป)

### วิเคราะห์ภาพ → เทมเพลต

ลากภาพสไลด์อ้างอิง (เช่นภาพที่เก็บไว้ใน `vault/references/`) มาวางในช่อง
"วิเคราะห์ภาพ → เทมเพลต" ที่แถบซ้าย เครื่องมือจะอ่านภาพบน canvas แล้วถอดโครงออกมา:

- สีพื้นหลังจากกรอบภาพ → เลือก class ให้เอง (`ink` `dark` `soft` หรือพื้นขาว)
  ภาพที่พื้นหลังไม่นิ่งทั้งใบจะได้ `photo` + `has-photo`
- แถวที่มีเนื้อหา → รวมเป็นบรรทัด แล้วรวมบรรทัดเป็นแถบตามระยะ leading
- ความสูงบรรทัดเทียบกับสไลด์ → `head xl` `head` `head sm` `body` `eyebrow` `stat`
- ช่องว่างแนวตั้งในแถบ → `specs` (3 ช่อง) `cols` (2 ช่อง) `speclist`
  ถ้ากลุ่มซ้ายแคบและชิดข้อความ = สัญลักษณ์นำหน้า → `checklist`
- แถบที่สีจัดจ้านและเนื้อแน่น → `mockup` (หรือ `photo` ถ้าคลุมเกือบทั้งใบ)
- ช่องว่างระหว่างแถบ → `gap` ตามสัดส่วนจริง ช่องที่กว้างที่สุดกลายเป็น `spacer`
- ทุกผลลัพธ์จบด้วย `foot` เสมอ

ผลลัพธ์แสดงเป็นแผนที่แถบทับบนภาพย่อ + รายการว่าแถบไหนกลายเป็นบล็อกอะไร
กด "เพิ่มเข้าชุด" เพื่อเอาเข้าชุดที่กำลังทำ (เทมเพลตจะเข้าไปอยู่ในหมวด
"จากภาพวิเคราะห์" ของแคตตาล็อกและติดไปกับ templates.json ที่ดาวน์โหลด)
หรือกด "ดาวน์โหลด JSON" เพื่อเอา object เทมเพลตใบเดียวไปวางใน `templates.json` เอง

> ไม่มี OCR และไม่เรียกเน็ต ตัววิเคราะห์ได้แค่ **โครง** ข้อความที่ออกมาเป็นคำตัวอย่าง
> ให้พิมพ์ทับ และภาพต้นฉบับจะถูกใส่ในช่องภาพของสไลด์ที่สร้างให้ เพื่อเทียบกับต้นฉบับได้ทันที

### เพิ่มเทมเพลตใหม่

แก้ `builder/templates.json` เพิ่ม object เดียว แล้วโหลดกลับเข้าเครื่องมือผ่านช่อง
"ชุดเทมเพลต (templates.json)" ในแถบซ้าย

```json
{ "id": "h11", "group": "head", "name": "แบบใหม่",
  "classes": ["dark"],
  "blocks": [
    { "type": "eyebrow", "text": "หัวเรื่อง" },
    { "type": "head", "size": "xl", "text": "พาดหัว" },
    { "type": "spacer" },
    { "type": "foot" }
  ]}
```

บล็อกที่ใช้ได้ 34 ชนิด เช่น `eyebrow` `head` `body` `pill` `mockup` `photo` `specs`
`speclist` `checklist` `dots` `tf` `cols` `sideby` `halfsplit` `lr` `grid4` `quote`
`bigword` `stat` `price` `band` `foot`

> หมายเหตุ: เบราว์เซอร์บล็อก `fetch` ไฟล์ในเครื่อง เครื่องมือจึงฝังชุดเทมเพลตไว้ใน
> `index.html` และให้โหลดไฟล์ JSON ทับผ่าน file picker แทน ถ้าแก้ `templates.json`
> แล้วอยากให้เป็นค่าเริ่มต้นถาวร ต้องแทนที่บล็อก `<script type="application/json" id="tplData">`
> ใน `index.html` ด้วย

## vault

เปิดโฟลเดอร์ `vault/` ด้วย Obsidian (Open folder as vault) แล้วเปิด plugin **Dataview**

- `Dashboard.md` — งานค้าง / พร้อมทำภาพ / ลงไปแล้ว / นับตามเสา
- `content-pillars.md` — 4 เสาคอนเทนต์ + หัวข้อตั้งต้น 10 เรื่อง
- `_templates/` — แม่แบบโน้ตโพสต์ รีเฟอเรนซ์ สินค้า

## เวิร์กโฟลว์

ไอเดีย → ร่างใน vault → เลือกรหัสเทมเพลต (h1, p2, m5 ...) → ทำภาพใน builder → export → ลงจริง

## ข้อจำกัดที่รู้อยู่

- ฟอนต์ Anton ไม่มี glyph ไทย ใช้ได้เฉพาะข้อความอังกฤษ
- สไตล์ที่ปรับรายข้อความเป็น inline style ไม่ถูกเซฟกลับเข้า `templates.json`
- ไม่มีการดึงข้อมูลจาก Facebook อัตโนมัติ (Meta ปิด CrowdTangle และจำกัด API)
  การอัปเดตเทมเพลตใช้วิธีเก็บภาพอ้างอิงเองแล้วถอดเป็นบล็อก JSON
